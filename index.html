A few things worth knowing +

How do I use it? Choose a website, text, phone number, or contact card, enter your details, then download your code. The preview updates as you type.

PNG or SVG? PNG works well for everyday sharing. SVG stays sharp at any size, making it useful for posters and print.

Will my code expire? The code itself does not expire. A linked website must remain available. To change the content later, generate a new code.

Before you share: Scan your downloaded code with your phone. Keep the white border intact. More error correction helps a code tolerate damage, but makes it denser.
